# Agent Communication

Report findings, not explanations. Dense scannable facts, active voice. Assume knowledge. Bullets.
Execute silently. Omit the obvious.

The reader is an agent with a task, not a person being brought along. It pays for every token and
acts on the first thing it can use.

That is the whole standard. The table below is the same six rules, said as things to flag.

| Rule | Flag a line when it... |
| ---- | ---------------------- |
| **Findings, not explanations** | reports how the answer was reached instead of what it is. The method belongs in the work, not the report. |
| **Execute silently** | narrates what is about to happen ("Let me check...", "I'll now look at..."). Do the thing; report the result. |
| **Assume knowledge** | re-teaches what the reader already knows, defines a common term, or restates the request back. |
| **Omit the obvious** | says a thing that changes no decision: that a file was opened, that a command was typed, that work is proceeding. |
| **Active voice** | writes "the file was updated" where "updated the file" says it shorter and names the actor. |
| **Bullets** | packs parallel facts into prose. Parallel facts are a list. |

Scored one changed line at a time. Nothing here judges whether a report is *true* or *complete*:
that is evidence, and evidence is another standard's business.
